# Ручная отправка IndexNow

Сначала опубликуйте `public/04a8dbffa3444bf8393a3913d0ef8f39.txt` обычным деплоем.
Адрес ключа: https://www.reactivator55.ru/04a8dbffa3444bf8393a3913d0ef8f39.txt
Файл должен возвращать HTTP 200 и ключ из имени файла. Скрипт проверяет это перед отправкой.

```powershell
# Проверка без сети
npm run indexnow:dry -- https://www.reactivator55.ru/contacts
npm run indexnow:dry -- --file urls.txt

# Реальная отправка: один или несколько вручную выбранных URL
npm run indexnow -- https://www.reactivator55.ru/contacts
npm run indexnow -- https://www.reactivator55.ru/about https://www.reactivator55.ru/services
npm run indexnow:file -- urls.txt
```

TXT: UTF-8, один полный URL на строку. Пустые строки и строки с `#` игнорируются.
Дубли удаляются в пределах одного запуска. Весь список проверяется до первого запроса;
ошибка любого URL отменяет весь запуск. Dry-run не проверяет опубликованный ключ, поскольку не использует сеть.

Разрешены главная, about, contacts, works, technology, services и публичные страницы
body-dimensions (комплекты и номера листов). Магазин, служебные пути, файлы, query,
fragment и кодированные пути запрещены. Новые разделы нужно явно добавить в `PUBLIC_PATHS`.
Наличие страниц не проверяется: можно сообщать об удалённых публичных URL (404/410).

POST отправляется только в https://yandex.com/indexnow, последовательно, максимум
10 000 URL на запрос. При ошибке скрипт останавливается без автоматических повторов;
успешные предыдущие батчи уже отправлены. HTTP 202 означает ожидание проверки ключа.
При сетевой ошибке результат текущего батча неизвестен. Перед повтором проверьте журнал.

Запускайте только для новых, изменённых и удалённых страниц. Автозапуска при build,
деплое, расписания и загрузки sitemap нет. Массовое обнаружение остаётся за sitemap.
Между повторными отправками одного URL Яндекс рекомендует выдерживать минимум 10 минут.
Приём запроса не гарантирует индексирование.

Документация Яндекса: https://yandex.ru/support/webmaster/ru/indexnow/reference
