==================================================
14. CLOUDFLARE R2 — АКТУАЛЬНАЯ СХЕМА
==================================================

Оригиналы чертежей хранятся приватно; прямой публичный доступ к ним не включать.
Превью хранятся отдельно и доступны публично.
Сайт читает приватные оригиналы через сервер с read-only доступом R2.
Переменные доступа сайта: R2_ACCESS_KEY_ID и R2_SECRET_ACCESS_KEY.
Временные upload-токены с правами Read & Write уже отозваны.
Старые upload-ключи удалены из .env.local; для работы сайта они не нужны.
Для будущей загрузки потребуется отдельный временный доступ с минимальными правами,
который следует отозвать после завершения загрузки.
Значения ключей и токенов в документацию и Git не включать.
