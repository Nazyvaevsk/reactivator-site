# База знаний Reactivator

Из папки проекта создайте материал:

    npm run content:new -- --title "Название статьи"
    npm run content:new -- --type news --title "Название новости"

Команда выводит путь нового .md файла. Откройте его любым текстовым редактором. Заголовок автоматически превращается в латинский slug; при совпадении добавляется номер. Существующие файлы не перезаписываются.

1. Заполните title и description в двойных кавычках. Внутренние кавычки удобнее писать «ёлочками».
2. Проверьте date (YYYY-MM-DD). Генератор использует текущую дату Омска.
3. Замените текст после второй строки ---.
4. Поставьте published: true, когда материал готов. false скрывает его из списка, маршрутов и sitemap. Дата сама по себе не откладывает публикацию: отложенного расписания нет.
5. Выполните npm run content:check и npm run build. После развёртывания сборки публикация появится на сайте.

В заголовке файла поддержаны только перечисленные поля: title, description, date, slug, type, published и необязательный tags: ["Измерения"]. Это простой поднабор front matter: каждое значение — JSON в одной строке, не произвольный YAML. Обязательные строки заключайте в двойные кавычки, published — true/false без кавычек. type — "article" в content/articles и "news" в content/news. Имя .md файла должно совпадать со slug. Не меняйте slug опубликованного материала без настройки перенаправления.

Текст: абзацы разделяются пустой строкой. Поддерживаются заголовки ## и ###, списки из строк с «- », **жирный текст**, ссылки [текст](/services) и [источник](https://example.com). Отделяйте заголовки и списки пустыми строками. H1 берётся из title; в тексте начинайте с ##. HTML, MDX, таблицы, изображения и вложенные списки не поддерживаются. Для первой версии обложки не нужны.

Все опубликованные материалы автоматически попадают в /articles, /articles/slug и sitemap.xml. Отдельного редактирования TSX не требуется. Ошибки полей и повторяющиеся slug останавливают сборку с указанием файла.

После проверки используйте git add с конкретными путями, затем git commit и git push, когда будете готовы публиковать. Генератор и сборка ничего не коммитят, не отправляют в Git и не вызывают IndexNow.
